## This repo

This repository is the source for the portfolio site. It is a Next.js 16 static export (English + Persian, cookie-based locale) deployed to GitHub Pages.

```bash
pnpm install
pnpm dev
```

| Command | What it does |
| --- | --- |
| `pnpm dev` | Local Next.js server |
| `pnpm build` | Static export to `out/` |
| `pnpm format` | Biome format + lint |

Push to `main` to deploy via GitHub Actions.
